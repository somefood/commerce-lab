코드는 "무엇을" 하는지만 말한다. "왜"는 여기 남는다.
파일에 붙은 주석은 그 파일이 사라지면 같이 사라지지만, ADR은 밖에 있어서 남는다.

**전부 사용자가 직접 쓴다.** Claude는 뼈대만 만든다.

## 쓰는 법

절 네 개가 전부다. **대안과 결과가 ADR의 값어치다** — 결정만 적힌 문서는
코드를 읽으면 알 수 있는 걸 반복하는 것이라 남길 이유가 없다.

| 절 | 쓰는 것 | 흔한 실수 |
|---|---|---|
| 배경 | 결정하기 **전** 상황. 무엇이 문제였나 | 해결책을 미리 쓴다 |
| 결정 | 무엇을 하기로 했나. 한 문장으로 시작 | 장황해진다 |
| 대안 | **버린 것과 버린 이유** | 여기를 비운다 ← 제일 아깝다 |
| 결과 | 얻은 것 **과 포기한 것** | 좋은 점만 쓴다 |

### 규칙

- **번복해도 지우지 않는다.** 상태를 `Superseded by ADR-XXXX`로 바꾸고 새 문서를 쓴다.
  틀린 판단의 기록도 자산이다 — 왜 그때 그렇게 봤는지가 남는다
- **날짜를 적는다.** "그때는 몰랐던 것"이 있으므로 시점이 의미를 갖는다
- **설명을 복붙하지 않는다.** 자기 언어로 다시 쓴 것만 면접에서 말할 수 있다
